# Dataset

This folder is intentionally left empty in the GitHub repo (see `.gitignore`) because image datasets are too large to version control directly.

## How to get the data

1. Download the Dogs vs Cats dataset from Kaggle: https://www.kaggle.com/c/dogs-vs-cats/data
2. Extract and arrange the images as follows:

```
data/
├── train/
│   ├── cats/   (e.g. cat.0.jpg, cat.1.jpg, ...)
│   └── dogs/   (e.g. dog.0.jpg, dog.1.jpg, ...)
└── test/
    ├── cats/
    └── dogs/
```
